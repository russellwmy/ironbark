# Prompt texts

Fixed texts for perplexity (`ironbark ppl --text`) and speed benchmarks (Mac CLI, iOS app via `ios/build.sh`). Benchmarks in the README use the first 3,000 characters (`-chars 3000`).

| File | Content | License |
|---|---|---|
| `prose.txt` | English Wikipedia articles from WikiText (Merity et al., 2016) | CC BY-SA 3.0 |
| `rust.txt` | Rust source from the Rust standard library and the `libm` crate | MIT / Apache-2.0 |
| `python.txt` | Python source from the CPython 3.14 standard library: `shutil.py` (file automation), then `statistics.py` (data analysis); first 120,000 characters | PSF-2.0 |
